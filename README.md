# Rawstack: VST3-синтезатор для FL Studio

Многоосцилляторный синтезатор аккордов с глайдами: частоты съезжаются и расходятся при смене аккорда, как в треке ALOBOI «just RAW». Внутри до 16 голосов на ноту, детюн, саб, октава вверх, фильтр, драйв, хорус, дилей, реверб и визуализация каждого осциллятора. Всего 56 параметров и 28 заводских пресетов, 18 из них построены на анализе трека.

## Как получить файл плагина

### Вариант 1: собрать в облаке через GitHub (ничего не нужно устанавливать)
1. Зарегистрируйтесь на github.com и создайте новый репозиторий (New repository, можно приватный).
2. На странице репозитория нажмите «uploading an existing file» и перетащите **все** файлы и папки из этого архива, включая папку `.github`. Если браузер не показывает скрытую папку `.github`, загрузите файл `.github/workflows/build.yml` вручную через «Add file → Create new file», указав путь `.github/workflows/build.yml`, и вставьте в него содержимое.
3. Откройте вкладку **Actions**. Сборка запустится сама и займёт 10–15 минут.
4. Когда появится зелёная галочка, откройте запуск и внизу в разделе **Artifacts** скачайте `Rawstack-Windows-VST3` (для Mac: `Rawstack-macOS-VST3`).

### Вариант 2: собрать на своём компьютере (Windows)
1. Установите бесплатную **Visual Studio 2022 Community** и при установке отметьте «Разработка классических приложений на C++». CMake входит в этот набор.
2. Установите **Git** (git-scm.com): нужен, чтобы CMake скачал библиотеку JUCE.
3. Запустите `build_windows.bat` двойным кликом. Первая сборка идёт 5–15 минут.
4. Готовый плагин появится в `build\Rawstack_artefacts\Release\VST3\Rawstack.vst3`.

## Установка в FL Studio
1. Скопируйте папку `Rawstack.vst3` целиком в `C:\Program Files\Common Files\VST3\` (на Mac: `/Library/Audio/Plug-Ins/VST3/`).
2. В FL Studio: Options → Manage plugins → Find installed plugins (Start scan).
3. Добавьте Rawstack как инструмент (Channel rack → + → Rawstack).

Отдельно собирается `Rawstack.exe` (Standalone): им можно проверить звук без FL Studio.

## Как играть
- Перетащите `midi/just_raw_chords_62bpm.mid` в пиано-ролл канала Rawstack и поставьте темп проекта 62 BPM. Это аккорды из анализа трека.
- Глайд срабатывает, когда новый аккорд начинается вплотную к концу предыдущего (легато). Если между аккордами есть пауза, новый аккорд стартует заново, без съезда.
- Режим «Аккорд из одной ноты» (группа «Аккорды»): одна клавиша играет целый аккорд лада. Для него есть файл `midi/just_raw_one_finger_62bpm.mid`; поставьте тональность G, лад «Мажор», режим «Нонаккорды лада».
- Пресеты переключаются в шапке окна или через стандартное меню пресетов FL Studio.

## Режимы глайда
- **Как в треке**: две нижние ноты (бас и квинта) едут параллельно, верхние голоса уходят к ближайшим нотам нового аккорда. Общие ноты остаются на месте.
- **Голосоведение**: каждый голос едет к ближайшей ноте.
- **Весь аккорд параллельно**: аккорд целиком сдвигается на интервал баса.
- **Разброс голосов**: голоса приезжают в разное время, частоты плывут сильнее.

## Структура
- `Source/Engine.h`: звуковой движок на чистом C++17 (без JUCE).
- `Source/Params.h`, `Source/Presets.h`: параметры и пресеты, сгенерированы из той же спецификации, что и веб-версия.
- `Source/PluginProcessor.*`, `Source/PluginEditor.*`: оболочка VST3 на JUCE 8 и окно с визуализацией.

Если сборка упадёт с ошибкой, скопируйте текст ошибки (из окна Actions или консоли) и пришлите его: поправлю.
